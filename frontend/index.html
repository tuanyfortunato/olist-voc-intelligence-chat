O que você quer saber sobre os clientes?

As respostas são escritas a partir dos comentários das avaliações, e cada afirmação mostra as avaliações que a sustentam. Toque nos números destacados, como 3, para ler o comentário original.

  1. 1Você pergunta sobre entrega, defeitos, atendimento ou elogios.
  2. 2A busca encontra os comentários mais parecidos com a pergunta.
  3. 3A resposta cita cada avaliação usada, para você conferir.

As respostas descrevem as avaliações recuperadas para cada pergunta, e não a base inteira. Dá para continuar a conversa com perguntas curtas, como "E nas notas altas?".
